VN SMART - LOJA DE ACESSÓRIOS + PAINEL ADMINISTRATIVO

O programa agora possui:
- Tela inicial com telefone do cliente
- Loja de Capas, Fones Bluetooth, Fones com fio e Carregadores
- Carrinho e registro local de pedidos
- Painel administrativo integrado
- Cadastro, edição, ativação/desativação e exclusão de produtos
- Alteração de preços sem editar o JavaScript
- Pesquisa e filtro de produtos
- Visualização dos últimos pedidos
- Cadastro, edição, ativação/desativação e exclusão de contas de vendedores
- Usuário e senha individuais para a equipe de vendas

COMO ABRIR
1. Extraia o ZIP.
2. Abra o arquivo index.html.
3. Para administrar, clique em "Acesso administrativo" ou "Painel administrativo".
4. Senha inicial do painel: 1234

ONDE OS DADOS FICAM
Os produtos e pedidos ficam salvos no navegador usando localStorage. Isso significa que esta versão é ótima para uso local em um computador, mas as alterações não sincronizam automaticamente entre computadores/celulares.

SEGURANÇA
A senha desta versão é apenas uma proteção de interface, pois o sistema é 100% front-end. Não use esta versão como sistema público com dados sensíveis sem colocar um servidor/banco de dados e autenticação real.

CONTAS DE VENDEDORES
No painel administrativo, a seção “Contas de vendedores” permite criar, editar, desativar e excluir usuários da equipe. Nesta versão, essas contas também são armazenadas no localStorage do navegador.


ACESSO DOS VENDEDORES
- Na tela inicial existe o botão "Acesso do vendedor".
- O vendedor deve informar o nome cadastrado pelo administrador e a senha definida para aquela conta.
- Contas desativadas pelo Admin não conseguem entrar.
- Após o login, o vendedor é levado ao "Painel do Vendedor".
- A sessão fica ativa apenas enquanto a aba/sessão do navegador estiver aberta.
- O login aceita o nome do vendedor e também o usuário cadastrado no Admin.
